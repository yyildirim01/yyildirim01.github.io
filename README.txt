FUTURE GAMES — GITHUB PAGES PACKAGE

1. Extract this ZIP.
2. Upload index.html, styles.css, CNAME, .nojekyll and the assets folder to the root of your GitHub Pages repository.
3. In GitHub: Settings > Pages > Build and deployment > Deploy from a branch.
4. Select the main branch and / (root), then save.

The CNAME file is already set to futuregames.nl.
